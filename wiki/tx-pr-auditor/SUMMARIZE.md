# tx-pr-auditor — Summary

`tx-pr-auditor` 1.0.0 is an active standalone platform skill that compares Final PO rows with ECC entitlement generated by `create-pr-cd`.

It owns workbook mapping, canonical identity, nine-DU resolution, entitlement matching, subcontractor and item validation, Invalid/Wrong/Duplicate/Normal classification, deterministic quantity consumption, evidence, audit reports, and annotated ECC copies.

Invocation:

```text
python src/main.py --input-manifest <workspace>/input.json
```

Public inputs are one `final_po` `.xlsx` and one or more `expected_ecc` `.xlsx` files. Results are authoritative through `result.json`. The registry release pins version `2026.08.10` and the exact upstream create-pr registry SHA-256.

The platform treats this as a separate job from `create-pr-cd` and does not reconstruct or sequence entitlement logic.
