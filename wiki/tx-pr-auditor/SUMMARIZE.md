# tx-pr-auditor — Summary

`tx-pr-auditor` compares Final PO rows with ECC entitlement generated by `create-pr-cd`.

It owns:

- Final PO and ECC workbook mapping.
- Canonical site, DU, item, subcontractor and quantity data.
- Entitlement matching and ambiguity checks.
- Invalid, Wrong, Duplicate and Normal classification.
- Deterministic quantity consumption.
- Evidence-backed audit reports and optional annotated ECC copies.

It must not read iEPMS or the PR model. Those belong to `create-pr-cd`.

Current direct entrypoint:

```text
python scripts/audit_final_po.py --final-po <file> --expected-ecc <file-or-directory> --output <file>
```

Target platform entrypoint:

```text
python <entrypoint> --input-manifest <workspace-relative-input.json>
```

The current platform hardcodes a combined workflow that generates TSS and TI ECC before running the auditor. In the target architecture, use separate jobs or a dedicated standalone composite Python skill. The generic platform must not own that domain sequence.
